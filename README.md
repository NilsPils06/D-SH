# D-SH (DASH)
A TUI dashboard that will be able to display system info, network info, current time and more. 

## Current version
> this segment will not always be updated on the dev branch

The current version only shows the current time, which updates on every input.

## How to use
First you need to build the project using cmake. I recommend adding a build folder before building.
```bash
mkdir build
cd build
cmake ..
make
./dashboard
```
